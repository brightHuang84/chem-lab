# 虚拟化学实验室（Virtual Chemistry Lab）

一个**纯前端、零依赖、可离线使用**的虚拟化学实验室：选择试剂和用量、设置容器与反应条件，引擎根据热力学与溶液化学数据判断**能否反应、产物是什么、放多少热、pH 多少、现象如何**。界面语言为简体中文，目的是帮助理解“化合物是怎么生成的”的**理论**，而不是提供真实操作步骤。

## 使用方法

直接双击（或用浏览器打开）`index.html` 即可，无需服务器、无需联网。推荐 Chrome / Edge / Firefox，1280×800 及以上分辨率最佳。

1. 左侧**试剂架**：搜索/筛选试剂，点击后查看化学式、摩尔质量、状态、密度、熔沸点、pKa/Kb、ΔfH°、溶解度、颜色与危险提示，再选择**量具**（电子天平 / 量筒 / 移液管 / 滴定管）按质量、体积或“体积 × 浓度”加入容器；多个“步骤”可分步加入。
2. 中间**工作台**：烧杯/试管/锥形瓶/量热计/坩埚、加热板（设定温度）、冰浴、磁力搅拌、催化剂槽、气氛（空气/氮气）、点火源、指示剂、电解装置；温度计、pH 计、电子天平、总体积实时显示。
3. 点击 **▶ 开始反应**：右侧显示结论、方程式与判据、限量试剂、物料衡算、产物、理论产量与可调“实际产率”、热效应（q = m·c·ΔT）、终态 pH 与型体分布、气体体积、沉淀质量、现象与危险提示；“计算日志”页给出逐步计算。烧杯里同步播放颜色渐变、气泡、沉淀、火焰、蒸汽等动画。
4. 顶部**示例实验**下拉框有 24 个预设实验（中和热、置换、沉淀、气体、钠与水、阿司匹林、酯化平衡、燃烧、热分解、电解……）。
5. **滴定模式**：选择待测液与标准液、浓度、指示剂；拖动滑块 / 点击“+1 滴”/“连续滴定”，实时绘制 pH–V 曲线，标出等当点（自动按 dpH/dV 极大值识别，多元酸给出多个突跃）、指示剂变色范围与锥形瓶颜色，并估算指示剂终点误差。
6. **实验笔记本**：随时“保存到笔记本”（浏览器 localStorage），可写备注、一键“载入并重做”，并导出 JSON / Markdown / CSV，也能导入 JSON。

> 小技巧：地址栏加 `#example=3` 会自动载入并运行第 3 个示例；`#view=titr`（或 `note`、`about`）直接切换页面。

## 反应引擎覆盖的类型

| 类型 | 判据 / 方法 |
| --- | --- |
| 酸碱中和、弱酸弱碱、缓冲、多元酸 | 电荷平衡方程 + 二分法精确求 pH（含 Kw、各级 pKa），金属离子水解（Fe³⁺、Al³⁺、Cu²⁺、Zn²⁺…） |
| 沉淀 | Ksp 与离子积 Q 比较；二分法求平衡沉淀量；两性氢氧化物过量碱溶解 |
| 配位 | Cu(NH₃)₄²⁺、Ag(NH₃)₂⁺、Zn(OH)₄²⁻、Fe(SCN)²⁺ 等（K 值） |
| 气体逸出 | 碳酸盐/碳酸氢盐/亚硫酸盐/硫化物 + 酸，铵盐 + 强碱，溶解度限度 |
| 置换与氧化还原 | 标准电极电势 E°cell > 0 且 Nernst 修正 pH；钝化、冷水惰性等动力学门槛；并给出 ΔG = −nFE |
| 有机 | Fischer 酯化（平衡常数 K → 平衡进度）、水杨酸 + 乙酸酐 → 阿司匹林、酸酐水解、皂化/酯水解、酚的 FeCl₃ 显色、强氧化剂 + 有机物 |
| 燃烧 | 燃料/O₂ 化学计量、点火条件、含水体系无法点燃 |
| 热分解 | ΔG = ΔH − TΔS 与动力学起始温度（CaCO₃、Cu(OH)₂、NaHCO₃ …） |
| 催化 | H₂O₂ 在 MnO₂/KI/Fe³⁺/Pt 上分解 |
| 浓酸 | 浓硫酸稀释热、脱水（蔗糖炭化） |
| 电解 | 阴阳极电势比较 + 过电势，法拉第定律计算析出量，分阶段 |
| 滴定 | 同一套 pH 求解器，逐点计算曲线 |

**诚实原则**：
- 已知不反应的组合 → 明确写“预计无反应”，并给出理由（如 E°cell < 0、全部离子可溶且不生成弱电解质）。
- 规则库未覆盖的组合 → 明确写“引擎无数据”，不会编造结果。
- 危险但常见的反应（钠 + 水、铝 + 碱、强氧化剂 + 有机物、浓硫酸稀释等）按真实热力学数据给出结果，并附带危险提示。
- 范围限制：涉及爆炸物、化学战剂、毒品合成的试剂组合一律返回“不支持”，且引擎中不含这些反应的规则或数据。

## 目录结构

```
index.html          页面
css/style.css       实验室风格样式
js/data.js          数据库：物种热力学数据、pKa、Ksp、E°、试剂架、指示剂、容器
js/engine.js        核心：pH 求解、颜色、平衡求解、账本 Ctx、安全过滤
js/react.js         反应规则（酸碱、沉淀、配位、氧化还原、有机、燃烧、热分解…）
js/sim.js           运行入口 run()、结果整理、电解、滴定曲线
js/viz.js           容器动画与滴定曲线绘制
js/app.js           界面逻辑（试剂架、工作台、结果、笔记本、滴定）
tests/run-tests.js  Node 验证脚本
```

`data.js / engine.js / react.js / sim.js` 为 UMD 写法，既可在浏览器使用，也可在 Node 中 `require('./js/sim.js')`。

## 验证

```bash
node tests/run-tests.js
```

脚本包含约 90 项检查，例如：

- 25 mL 0.1 M HCl + 25 mL 0.1 M NaOH：pH = 7.00；放热 Q = 0.140 kJ（2.5 mmol × 55.8 kJ/mol）。
  **说明**：需求中“ΔT ≈ 0.14 K”对应的其实是 0.14 *kJ*；50 g 水溶液 (c ≈ 4.18 J/g·K) 的理想绝热温升是 0.67 K（含 45 J/K 玻璃烧杯则约 0.55 K），引擎按 q = mcΔT 给出该值。
- 0.1 M 醋酸 pH = 2.88；半中和缓冲 pH = pKa = 4.76；0.1 M NaOH pH = 13.00；0.1 M NH₃ pH = 11.12。
- Zn + CuSO₄ 反应（析出 Cu 0.318 g，ΔH = −1.09 kJ），Cu + ZnSO₄ 不反应（E°cell = −1.104 V）。
- AgNO₃ + NaCl → AgCl 0.358 g；BaSO₄ 0.583 g。
- 2.0 g 水杨酸 + 过量乙酸酐 → 阿司匹林理论产量 2.609 g（75% 产率 1.957 g）。
- 滴定曲线：HCl/NaOH 等当点 25.00 mL、pH 7.00；醋酸/NaOH pH 8.73；H₃PO₄、Na₂CO₃ 两个突跃（25/50 mL）。
- 全部反应事件的原子与电荷守恒检查；“引擎无数据”“不支持”分支。

## 局限

- 温度变化按理想绝热量热估算（水溶液比热 ≈ 4.18 J/g·K，加容器热容）；燃烧火焰温度不适用该公式。
- ΔfH° 取自常用教材/NIST 数据，个别有机物与配合物为近似值，缺数据时会明确提示“热效应未计入”。
- 活度系数取 1（稀溶液近似），浓溶液（如浓酸）的 pH 为理想估算。
- 动力学只用“规则门槛”（温度、催化剂、钝化）近似，不模拟反应速率曲线。
- 这是教学用的理论模拟器，**不是实验操作指南**。
